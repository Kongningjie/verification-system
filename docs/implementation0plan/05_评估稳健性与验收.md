# 阶段 5：评估、稳健性与验收

## 阶段目标

使用真实代表性材料验证端到端质量，修复阻断问题，完成安全、性能、稳定性和文档收口。不得通过降低冻结指标或修改标注数据宣告成功。

## 开始条件

- 阶段 4 已完成 Review 和全部测试。
- 用户明确批准进入阶段 5。
- 用户能够提供或确认至少 5 组代表性任务包及人工标注。
- 冻结方案哈希不变。

## 实现范围

### 1. 评估数据规范

在 `evals/` 建立：

```text
evals/
├── fixtures/{case_id}/
│   ├── manual.docx
│   ├── template.docx
│   ├── project.json
│   └── evidence/
├── expected/{case_id}.json
└── reports/
```

标注格式必须包含：

- 预期核对项及是否关键。
- 来源批注或通用规则 ID。
- 预期结论。
- 允许的证据位置或证据事实。
- 人工无法确定项标记。

不得把真实 API Key、敏感生产材料或未获授权数据提交到 Git。

### 2. 指标执行器

自动计算：

- 关键核对项召回率。
- 全部核对项召回率。
- 可判定项结论准确率。
- 证据可追溯率。
- 虚构证据次数。
- 单任务端到端耗时。
- Token 用量和模型耗时。
- 三次重复运行的结论稳定性。

指标计算逻辑必须有独立单元测试，评估报告应能追溯到具体任务与核对项。

### 3. 冻结验收门槛

| 指标 | 门槛 |
|---|---:|
| 关键核对项召回率 | 100% |
| 全部核对项召回率 | ≥95% |
| 可判定核对项结论准确率 | ≥90% |
| 证据可追溯率 | 100% |
| 虚构证据 | 0 次 |
| 单任务端到端耗时 | ≤5 分钟，不含人工等待 |
| 通用规则重复运行一致性 | 100% |

同一输入运行三次时，LLM 不得在 `PASS` 与 `FAIL` 间直接漂移；独立判断不一致必须进入 `NEEDS_REVIEW`。

### 4. 问题归因与修复

未达标问题必须归入：

- 解析错误。
- 清单生成错误。
- 证据匹配错误。
- 规则执行错误。
- 模型判断错误。
- 聚合错误。
- UI/报告错误。

只允许修复根因，不允许：

- 修改冻结指标。
- 删除困难样例。
- 将错误标注为“人工无法判断”规避统计。
- 针对样例文件名或内容硬编码答案。
- 无授权修改冻结方案。

### 5. 稳健性与安全收口

执行：

- 恶意 DOCX/ZIP/XML、路径穿越、超大图片和损坏文件测试。
- Prompt Injection 测试：上传材料不得改变系统指令或获得工具能力。
- 日志、数据库、报告和前端响应的密钥/敏感内容扫描。
- 任务取消、进程重启、磁盘写入失败和网络异常恢复。
- 两任务排队与单任务三路并发验证。
- 数据库迁移从空库、升级和回退验证。
- 前端主要流程浏览器验收。

### 6. 文档收口

更新非冻结文档：

- README 安装、启动、测试与常见问题。
- `.env.example` 完整字段说明。
- 已知限制。
- 评估运行说明。
- 当前模型与提示词版本。
- 数据清理说明。

不得修改冻结方案；若文档发现冻结方案错误，只能提出变更申请。

## 必做测试

- 全部后端单元与集成测试。
- 全部前端类型检查、构建与关键交互测试。
- 5 组任务包完整评估。
- 每组真实模型运行三次。
- Fake Agent 端到端回归。
- 安全负例套件。
- 实际健康接口、上传、清单、核对、复核、报告和删除冒烟测试。

## Review 清单

- 评估数据是否与实现相互独立。
- 是否存在为通过样例而硬编码。
- 是否遗漏失败任务或只报告成功样例。
- 指标分母和排除规则是否正确。
- 虚构证据检查是否验证真实 evidence ID。
- 是否把 Fake Agent 指标当作真实质量指标。
- 日志、报告和前端是否泄露敏感数据。
- 是否修改冻结方案、门槛或标注来规避失败。

## 完成门槛

- 冻结方案全部指标达到门槛。
- Review 无 P0/P1，所有 P2 已修复或由用户接受。
- 测试、评估和安全报告完整。
- README 可由新的本地环境复现安装和运行。
- 冻结方案哈希仍为原值。
- 向用户提交最终验收报告；是否宣布 MVP 完成由用户决定。

## 未达标时的停止规则

任一冻结指标未达标时：

1. 明确报告未达标指标和具体样例。
2. 给出问题归因和建议修复范围。
3. 不修改冻结方案。
4. 不自行宣布完成。
5. 等待用户决定继续修复、调整业务输入或正式发起冻结方案变更。
