## 2. 实现内容

### 2.1 人工复核与审计

- 新增 `review_record` 表及 Alembic 迁移 `20260926_0005`。
- 人工操作只更新 `final_conclusion` 和人工改判标志，不覆盖 `system_conclusion`。
- 关键项任何改判必须填写说明；`FAIL`、`ERROR`、`NEEDS_REVIEW` 改为 `PASS` 必须填写说明。
- 复核人由服务端 `REVIEWER_NAME` 提供，复核历史按时间完整展示和导出。
- 通过带旧最终结论条件的更新实现并发冲突检测，冲突返回 `REVIEW_CONFLICT`，避免静默覆盖。

### 2.2 报告与安全下载

- 新增 `report` 表、报告生成服务和按任务 ID/报告 ID 下载接口。
- Excel 固定生成 `Summary`、`Results`、`Evidence`、`ReviewLog`、`Metadata` 五个工作表。
- JSON 完整导出任务、文件、清单快照、结果、证据、复核记录和执行元数据。
- 报告不包含 API Key、完整提示词、图片 Base64、内部存储路径或绝对路径；Excel 文本执行公式注入防护。
- 报告先写临时文件再原子替换，失败记录为 `FAILED` 且不改变核对任务状态。
- 已生成报告文件不随后续人工复核变化，满足生成时最终结论快照语义。

### 2.3 前端任务闭环

- 任务中心显示名称、创建时间、状态、阶段、进度和最终结论统计，支持进入与二次确认删除。
- 新建任务按说明书、模板、项目 JSON 和依据材料分区上传，并在前端检查必填、扩展名、大小和重复选择。
- 结果页支持按最终结论、执行通道、严重等级和人工修改分页筛选。
- 详情展示核对要求、系统/最终结论、目标/来源证据、逻辑定位、模型差异、缺失信息、图片缩略图及复核历史。
- SSE 事件包含稳定事件 ID、类型、阶段、进度和时间；断线后先查询任务最新状态再重连。
- 页面使用 Vue 文本插值展示用户材料，不使用 `v-html`。

### 2.4 删除、错误与可观测性

- 删除时先将任务目录移动到同磁盘暂存路径，再提交数据库删除，最后清理暂存目录。
- 数据库删除失败时恢复原目录；文件清理失败时保留可识别暂存目录，并允许使用同一任务 ID 重试。
- 活动中及排队任务禁止直接删除；默认 `RETENTION_DAYS` 为空，不启用自动清理。
- 业务错误继续统一返回 `code`、`message`、`details`、`request_id`。
- 新增 JSON 业务日志格式，稳定包含时间、级别、请求 ID、任务、阶段、核对项、操作、耗时和错误码字段。
